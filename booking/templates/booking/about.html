About SpaceFlow

A booking platform built to simplify campus room reservations.

SpaceFlow helps users discover venues, submit authenticated requests, and track approval status.

Platform purpose

This platform centralizes room discovery and booking requests for event spaces such as halls, classrooms, conference rooms, studios, and outdoor areas.

How to use it

  • Open the room list and filter spaces by type or capacity.
  • Review the room detail page for venue information and image.
  • Login, submit the booking form, and wait for approval.
  • Administrators manage rooms and booking statuses in Django Admin.

MVC explanation

The project follows Django's MVC-style structure.

  • models.py stores the data structure for rooms and bookings.
  • views.py handles request logic, validation flow, and page context.
  • templates render the presentation layer shown to users.
  • urls.py maps browser routes to the correct views.

Database choice

SQLite is intentionally used for this university demo.

SQLite keeps setup simple, works well for a single demo instance, and is fully supported by Django migrations. PostgreSQL would be a future scalability upgrade, not a requirement for this project scope.
